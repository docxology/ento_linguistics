# Standards and verification

The executable coverage floor is 90% combined statement/branch coverage for project source; it is not a separate 90% branch-only threshold. Use the full suite to measure it; a claim in documentation is not a gate result.

Public analysis interfaces include type annotations and documentation. Source-layer analysis uses real stored corpora. Tests use numerical controls, real files and real local HTTP, without mocking frameworks. Explicit negative controls exercise malformed records, stale cache content, invalid limits, missing receipts, renderer failure and pathological graph weights.

The standalone build generates all available layers and propagates required failures. The manuscript retains numerical placeholders. PDF rendering validates content receipts, checks subprocess exits and rejects unresolved references, citations and missing glyphs. A successful process does not establish relevance, licensing, independent annotation, human agreement or causal effects.

Current receipts and measured results are documented in [review_20261006.md](review_20261006.md). Legacy static corpus/count tables have been replaced with links to actual artifacts in [the documentation index](README.md).

Source provenance gaps, repeated text under distinct source IDs, convenience-sample retrieval, OCR quality, statistical dependence and bounded analyses are substantive research limitations, not failures to hide. They are documented in [reproducibility.md](reproducibility.md) and the revised manuscript.
