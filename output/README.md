# Generated artifacts and retained evidence

The standalone repository versions selected research artifacts and verification records here. This directory is not a disposable or universally ignored parent-template output tree.

| Path | Meaning |
| --- | --- |
| [data/](data/README.md) | Managed core statistics, vocabulary exports and completed analysis manifest |
| [figures/](figures/README.md) | Managed registered core PNG figures |
| [pdf/](pdf/README.md) | Active unpublished paper build and toolchain intermediates |
| [extensions/](extensions/network_robustness/network_robustness.md) | Independently receipted fixed-margin primary and sensitivity protocols |
| [.checkpoints/](.checkpoints/README.md) | Content-bound recovery checkpoints; not final completion receipts |
| [reports/](reports/README.md) | Custody report and historical generic report snapshots |
| [logs/](logs/README.md) | Logs whose scope depends on the recorded run |
| [review-main-20261008/](review-main-20261008/SUMMARY.md) | Verified 49-page draft candidate and independent gate |
| releases/ and dated review directories | Archived file identities, execution logs, negative controls and publication receipts |
| web/ | Retained legacy combined Markdown; no active standalone web build |

Use [verification](../docs/reference/verification.md) for source/PDF identities and measured check results. The top-level published PDF is distinct from the active draft. Generate through [maintained entry points](../scripts/README.md); preserve historical evidence outside managed directories and stage only intended public files. Scratch rasters, temporary test trees and private logs may be local even when their containing directory has tracked records.
